
## SNOW Analysis Tool

A data analysis tool for ServiceNow (SNOW) incident management. Process CSV files containing incidents to generate insights, categorizations, and visualizations. Access via CLI or web interface.

### Features

- **Data Loading**: Loads incident data from CSV files with encoding fallback support (UTF-8, Latin-1, CP1252).
- **Issue Categorization**: Automatically categorizes incidents into:
  - CHECKOUT ISSUES
  - STOCK SEARCH ISSUES
  - VAT ISSUES
  - PAYMENT ISSUES
  - STOCK/INVENTORY ISSUES
  - CART ISSUES
  - INVOICE ISSUES
  - UNCATEGORIZED
- **Problem ID Aggregation**: Groups incidents by Problem ID, assignment group, and title, with incident counts.
- **Analysis Summary**: Provides total incidents, tickets with problems, and unique issue type counts.
- **Visualizations**: 
  - Pie chart showing incident distribution by category
  - Table image displaying Problem IDs, Assignment Groups, Titles, and incident counts
- **Web Interface**: FastAPI-based web UI for easy file upload and analysis.
- **CLI**: Command-line interface for batch processing.
- **Output**: Saves visualizations to the output directory.

### Generate Mock Data (First Time Setup)

To use the application with sample data, generate mock data in this specific order:

#### Step 1: Generate Metric Instances
```bash
python "generate moc data/generate_random_moc_metrics.py"
```
Creates `output/metric_instance.csv` with 400 sample metric records.

#### Step 2: Generate Problems
```bash
python "generate moc data/generate_random_moc_problem.py"
```
Creates `output/problems.csv` with problem records linked to incidents. Requires both `incident.csv` and `metric_instance.csv`.

#### Step 3: Generate Incidents
```bash
python "generate moc data/genrate_moc_data_incident.py"
```
Creates `output/incident.csv` with incidents linked to the metrics. Requires `metric_instance.csv` from Step 1.



**Example Complete Setup:**
```bash
# Generate all mock data in order
python "generate moc data/generate_random_moc_metrics.py"
python "generate moc data/generate_random_moc_problem.py"
python "generate moc data/genrate_moc_data_incident.py"

# Then run the analysis
python data_analysis.py
```

All generated files are automatically saved to the `output/` folder and ready for analysis.

### Usage

#### Option 1: Command Line (CLI)

Run the analysis script with the default CSV files from the output folder:

```bash
python data_analysis.py
```

The script looks for CSV files in the `output/` folder:
- `output/incident.csv`
- `output/problems.csv`
- `output/metric_instance.csv`

Outputs:
- Console summary with statistics
- Pie chart visualization (`issues_distribution.png`)
- Problem report table (`problem_report_table.png`)

#### Option 2: Web Interface (FastAPI)

Start the web server:

```bash
python fastapi_app.py
```

Then open your browser to:
```
http://localhost:8000
```

**Web Features:**
- Upload incident CSV files directly via the web form
- Or specify file paths on your machine
- Automatically uses files from `output/` folder if available
- View generated visualizations in the browser
- Download visualization images
- Browse gallery of all generated visualizations at `/gallery`

### Input Data Format

#### incident.csv

Required columns:
- `number`: Incident number (will be normalized to uppercase)
- `short_description`: Brief description of the incident
- `description`: Full incident description
- `problem_id`: Associated Problem ID (format: PRB followed by numbers, e.g., PRB001)
- `assignment_group`: Assignment group responsible for the incident

Example:
```csv
number,short_description,description,problem_id,assignment_group
INC0001,Checkout timeout,408 request timeout during checkout,PRB001,CHECKOUT_TEAM
INC0002,Stock sync error,Inventory levels not syncing,PRB002,INVENTORY_TEAM
```

#### metric_instance.csv

Generated by `generate_random_moc_metrics.py`. Contains:
- `sys_created_on`: Creation timestamp
- `definition`: Metric definition
- `id`: Incident reference
- `value`: Metric value
- `metric_start`: Start timestamp
- `metric_end`: End timestamp
- `duration`: Duration in seconds
- `calculation_complete`: Completion status

#### problems.csv

Generated by `generate_random_moc_problem.py`. Contains:
- `number`: Problem ID
- `sys_created_on`: Creation timestamp
- `short_description`: Problem description
- `priority`: Priority level
- `assignment_group`: Assignment group
